# NEPSE bring-your-own-data kit (Round E, E.3)

The kit runs the existing evaluations on CSV files the user
supplies — a NEPSE price CSV and a NEPSE floorsheet CSV, plus
an optional event CSV. It fetches nothing. It names no NEPSE
data provider, API or download page anywhere: the data is
"user-supplied", full stop. The protocol (schemas, importer
checks, evaluation rules) is `docs/nepse-byod-protocol.md`;
the kit is `toolkit/nepse_byod.py`; the CLI is
`scripts/nepse_byod_run.py`.

## One command

```text
python3 scripts/nepse_byod_run.py --prices <price.csv> \
    --floorsheet <floorsheet.csv> --source "<label>" \
    [--events <events.csv>] [--trade-value 100000] \
    [--out reports/nepse-byod]
```

`--source` is required: unsourced data is refused, not
loaded. The run writes `nepse-byod-report.json` (the full
report) and `nepse-byod-report.md` (a short summary) into
`--out`. Exit 0 on a completed report; exit 2 when the kit
refuses the data — the refusal names the file and the line.

The price CSV is the multi-symbol form
`symbol,sector,date,close,high,low,volume`, or the
single-symbol form `date,close,high,low,volume` with
`--single-symbol`. The floorsheet CSV is
`date,broker,symbol,side,quantity,price`. The event CSV is
`symbol,event_date,event_type[,detail]`.

## What runs

- Forecast harness (`run_full_evaluation`, train 252, purge
  5, embargo 5) and the direction models (walk-forward,
  train 252) — symbols with fewer than 260 closes are
  excluded from these two and recorded.
- Cross-sectional ranking — momentum-only, because no
  fundamentals are involved: value/quality components are
  absent by design. Ranking bars are every 21 bars from bar
  126 while 21 forward bars fit; costs use the NEPSE
  schedule at `--trade-value` per name. Symbols with fewer
  than 150 closes are excluded; fewer than 10 qualifying
  symbols refuses the ranking.
- Event study — the market model uses the alphabetically
  first symbol's series as the market proxy when its dates
  align with the event symbol's; otherwise the event is
  mean-adjusted, and the report records which model each
  event used.
- Floorsheet analytics — broker net flow and per-symbol flow.
  Descriptive only: a broker buying heavily is a fact about
  the supplied rows, not a recommendation. Research only.
  Never investment advice.

The direction-rule baseline falls back to the base rate for
symbols with no pre-registered rule (the track record's rules
live in `toolkit/direction_rules.py` and are never extended
here) — no rule is invented for a new symbol.

## Fixture run (synthetic, reproducible)

The bundled fixtures are synthetic — invented prices and
invented brokers, generated by a geometric random walk from
seed 20261115, never real market data. Run on 2026-11-15:

- 12 symbols x 280 bars, 2025-01-01 to 2026-01-27;
  floorsheet 120 rows across 4 brokers.
- Harness: 11 models, 324 pooled volatility folds. Pooled
  mean QLIKE: EWMA −6.7255, GARCH-lite −6.7212, naive
  −6.7009 — both volatility models beat the naive baseline
  on mean QLIKE but the verdict is "no edge" (the 95% CI on
  the difference includes zero). Pooled direction accuracy:
  51–54% across models, no model above the naive baseline
  by more than noise.
- Direction: 27 test folds per symbol.
- Ranking: 7 ranking bars, NEPSE round-trip cost 0.74% at
  Rs 100,000 per name. Momentum (and composite, identical
  when only momentum exists): mean net spread +0.80pp per
  21-bar window, 95% CI [−5.26pp, +7.56pp], "no edge".
  Mean baseline net return −1.03%.
- Event study: 4 events, market proxy API. CAAR −5.31%,
  t = −1.20, bootstrap p = 0.153, not significant, small-n
  caveat applies (n = 4). One event is individually
  significant (NABIL dividend, CAR −17.50%, p = 0.007) —
  a single synthetic event, not a finding.

Reproduce it with:

```text
python3 scripts/nepse_byod_run.py \
    --prices tests/fixtures/nepse_byod_prices_SYNTHETIC.csv \
    --floorsheet tests/fixtures/nepse_byod_floorsheet_SYNTHETIC.csv \
    --events tests/fixtures/nepse_byod_events_SYNTHETIC.csv \
    --source "synthetic fixture, generated from seed 20261115"
```

Tests: `tests/test_nepse_byod.py` (15 tests, no network).
