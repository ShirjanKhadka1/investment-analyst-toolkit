## Release notes (copy into the GitHub release)

### v0.9.0 — data layer + front door

**The one-command terminal is the front door.** Clone, run one command, get
a research dashboard in seconds — no keys, no installs beyond Python 3.10+:

```bash
git clone https://github.com/ShirjanKhadka1/investment-analyst-toolkit.git
cd investment-analyst-toolkit
python -m toolkit.terminal demo.csv
```

Timed 2026-11-07: clean clone + run took 2.3 seconds. A free terminal that
turns any daily-bars CSV into indicators, setups, honest Time-Machine odds
and a risk gate — with every number reproducible.

**What changed**

- **Data layer (Phase 2):** provider-contract connectors (caller CSVs first,
  then Yahoo, Stooq, CoinGecko, ECB, World Bank), per-source TTL cache,
  bounded retries, freshness SLA in `data_health.json`, derived refresh with
  `as_of` provenance.
- **Front door (Phase 3):** README rewritten around the terminal (hook,
  install + first result, worked example with numbers pinned by tests,
  honest comparison table, Mermaid architecture diagram, roadmap,
  good-first-issues as text). Demo assets generated from a real run
  (`docs/demo-transcript.md`, `docs/demo.svg`, `docs/demo.gif`).
  Nepali front door: `README.ne.md`.
- **Lint:** `ruff check` clean across the whole repo (7 pre-existing errors
  in `scripts/` fixed).
- **Track record: n=0 settled** — no research call has been logged and
  settled yet; the scoreboard stays at n=0 until a real call settles.
  See `docs/track-record.md`.

**Tests:** 509/509 passing (fresh clone, Python 3.12, pytest 9.2.0),
coverage 91%.

**Research only, not investment advice.** No live trading, no orders,
no execution anywhere in this repo.
