Investment Analyst Toolkit

NEPSE, native: sourced frictions, effective-dated rules, the Time Machine and a zero-LLM rules mode — NEPSE is the tested, default market, and NEPSE data is CSV-only by design.

World markets, supported: US, India, UK, crypto and FX via sourced market profiles, SEC EDGAR fundamentals and keyless public connectors — labelled tested or experimental in docs/global-evidence.md.

A free terminal that turns any daily-bars CSV into indicators, setups, honest Time-Machine odds and a risk gate — with every number reproducible. Zero keys, zero dependencies.

Research only, not investment advice. No live trading, no orders, no execution anywhere in this repo.

One command

git clone https://github.com/ShirjanKhadka1/investment-analyst-toolkit.git
cd investment-analyst-toolkit
python -m toolkit.terminal demo.csv

Clone, run one command, get a research dashboard in seconds — no keys, no installs beyond Python 3.10+.

demo.csv is synthetic sample data, not real market data: a seeded random walk (seed 5, start 1000, daily drift +0.12%, volatility 1.2%), 80 weekday bars 2026-07-20 to 2026-11-06, NEPSE-style prices in NPR, symbol DEMO. Generated 2026-11-07; the provenance is in the file header.
