# Cross-sectional ranking + event-study evaluation protocol (PR 8.3) — PRE-REGISTERED

Written 2026-11-14, **before any evaluation was run**. This protocol
fixes the universe, proxies, decile method, cost model, event-study
windows, significance test and model count in advance. No parameter
is tuned after seeing results; if the results are bad, the bad result
is published, not re-tuned away. Model rules (MASTER-ROADMAP.md): a
model must beat its baseline out of sample or be labelled "no edge".

## What this evaluation is — and is not

This evaluation runs **entirely on synthetic data**, generated by
`scripts/evaluate_cross_sectional.py` from a fixed seed. It validates
the pipeline and the decision rule — that scores rank, deciles form,
costs are charged, spreads and CIs compute, and the verdict rule has
both branches — it is **not** evidence about any real market. No
real-market edge is claimed anywhere in this PR, and no verdict here
may be quoted as a statement about NEPSE, US equities, or any real
symbol. A real-data evaluation needs real user-supplied CSVs (NEPSE)
or EDGAR fundamentals plus Yahoo prices (global); the code for that
path is tested on fixtures, and the evaluation script documents how
to run it. No live EDGAR or Yahoo call happens in this evaluation
or in any test: EDGAR is network, and the tests follow the existing
`tests/test_edgar.py` fixture pattern.

## Pre-registered summary (everything fixed before the first run)

- **Ranking rules tried: 4** — momentum, value, quality, composite
  (equal-weight mean of the three proxies' cross-sectional z-scores)
  — plus an equal-weight universe baseline, which is not a tried
  model. No parameter search was run and none will be run.
- **Universe:** 20 synthetic symbols, 400 daily closes each,
  generated from seed 20261114 (see "Synthetic data" below).
- **Deciles:** 10 deciles, 2 names each, decile 10 = top.
- **Rebalances:** 12 monthly ranking dates (every 21 bars), 21-day
  forward returns after each ranking date. Scores use closes up to
  the ranking date only; forward returns start the next bar. No
  look-ahead.
- **Costs:** charged on every rebalance, both legs (buy + sell).
  NEPSE: the sourced schedule via
  `toolkit.strategy_backtester.trade_cost("nepse", trade_value)`,
  trade value NPR 100,000 per name. Global: explicit flat
  `cost_fraction = 0.001` per leg. Capital gains tax is NOT charged
  (lot gain / holding period not tracked — same exclusion as the
  portfolio backtester, stated on the model card, not hidden).
- **Spread:** top-decile mean net forward return minus bottom-decile
  mean net forward return, per rebalance; the verdict uses the mean
  spread across the 12 rebalances.
- **Significance:** 95% percentile bootstrap CI on the mean spread,
  2000 resamples, seed 20261114, resampling the 12 per-rebalance
  spreads.
- **Event study:** 6 synthetic NEPSE corporate-action events + 2
  synthetic global earnings events from the bundled demo CSVs;
  estimation window [-250, -31] trading days before the event,
  event window [-5, +5]; market-model OLS abnormal returns;
  cumulative abnormal return (CAR) per event, cumulative average
  abnormal return (CAAR) across events; significance by t-test AND
  a seeded bootstrap p-value (2000 resamples, seed 20261114).
- **Floorsheet:** no statistical verdict. The importer and its
  broker-flow analytics are validated by known-answer tests on the
  bundled synthetic demo floorsheet; the evaluation script reports
  the computed analytics as values, not as a verdict.

## Synthetic data (fixed here, generated by the script)

- Prices: per symbol, 400 closes from a geometric random walk,
  `random.Random(20261114)`, daily log-return drift 0, daily
  volatility 2%, starting close 100. **No factor structure is
  planted**: forward returns are independent of every proxy by
  construction, so the expected verdict on every ranking rule is
  "no edge". A "beats zero" verdict on this data would mean the
  pipeline or the seed is broken, not that an edge exists.
- Fundamentals: per symbol, one synthetic annual snapshot from the
  same seeded stream — net income, stockholders' equity, revenues,
  gross profit, total assets, market capitalisation — drawn
  independently of the price path (log-uniform in stated ranges:
  market cap NPR 1–10 billion equivalent units; net income 1–15%
  of market cap; equity 20–80% of market cap; revenues 50–200% of
  market cap; gross profit 20–60% of revenues; assets 80–150% of
  market cap). The values are inputs to the proxy arithmetic only;
  they are not real company data and carry no provenance.
- Market index for the event study: a synthetic 400-bar series from
  the same seeded stream (drift 0, daily volatility 1.5%).
- Event prices: per event symbol, a 400-bar synthetic series from
  the same seeded stream, with the event date placed at bar 300 so
  the estimation window [-250, -31] and event window [-5, +5] both
  fit inside the series. No price jump is planted at any event, so
  the expected event-study outcome is "no significant abnormal
  return".

## Proxies (fixed here)

All proxies are computed from data available at the ranking date
only.

- **Momentum:** 6-minus-1 momentum — total return from 126 bars
  ago to 21 bars ago, `P[t-21] / P[t-126] - 1`. The most recent 21
  bars are skipped (the standard 12-1 skip, shortened to the
  6-month formation this synthetic window supports).
- **Value:** earnings yield `NetIncomeLoss / market_cap` and
  book-to-price `StockholdersEquity / market_cap`; the value proxy
  is the mean of the two cross-sectional z-scores.
- **Quality:** return on equity `NetIncomeLoss / StockholdersEquity`
  and gross margin `GrossProfit / Revenues`; the quality proxy is
  the mean of the two cross-sectional z-scores.
- **Composite:** mean of the momentum, value and quality
  cross-sectional z-scores (equal weight).
- EDGAR bridge: `proxies_from_edgar` fetches the five XBRL concepts
  (`us-gaap: NetIncomeLoss`, `StockholdersEquity`, `Revenues`,
  `GrossProfit`, `Assets`) via the existing `toolkit/edgar.py`
  `get_fundamentals` and computes the same value/quality proxies
  from the latest audited annual (10-K) values, carrying each
  value's form, filing date and period end as provenance. A missing
  concept raises — no value is ever invented or defaulted. The
  bridge is exercised in tests on fixture facts only, never live.

## Decile method (fixed here)

- Scores are ranked cross-sectionally at each ranking date;
  `assign_deciles` sorts ascending and assigns decile
  `floor(rank * 10 / n) + 1` (capped at 10), so decile 10 holds the
  highest scores. Ties are broken by symbol name so the assignment
  is deterministic.
- A decile portfolio holds its names equal-weighted for the 21-day
  forward window, then rebalances. The spread is long decile 10,
  short decile 1, each leg equal-weighted, each leg charged its own
  round-trip costs.
- The baseline is the equal-weight universe return over the same
  forward windows, net of the same costs. The spread verdict does
  not use the baseline; the baseline is reported for scale only.

## Cost model (fixed here)

- NEPSE leg cost: `trade_cost("nepse", 100_000)` — broker slab +
  SEBON 0.015% + DP Rs 25 per scrip per trade, from the sourced
  schedule of 2026-10-28. At NPR 100,000 the slab rate is 0.33%,
  so one leg costs NPR 330 + 15 + 25 = NPR 370, i.e. 0.37% of
  traded value; a round trip costs 0.74%. CGT excluded (see above).
- Global leg cost: flat `cost_fraction = 0.001` (0.10% per leg,
  0.20% round trip), caller-supplied — no sourced US fee schedule
  exists, so the backtester's `UnknownCostError` rule applies and
  an explicit fraction is required rather than an assumed zero.
- Costs are deducted from forward returns as fractions of traded
  value: `net_return = gross_return - round_trip_cost_fraction`.
  A spread that is positive before costs and zero or negative
  after them is "no edge".

## Event-study method (fixed here)

- **Estimation window:** trading days [-250, -31] relative to the
  event date (220 bars), ending 30 days before the event so
  pre-event drift cannot contaminate the normal-return model.
- **Event window:** [-5, +5] trading days (11 bars).
- **Normal returns:** market model, OLS alpha/beta of the symbol's
  daily returns on the market index's daily returns over the
  estimation window. Mean-adjusted returns (estimation-window mean
  as the normal return) are the fallback when the caller supplies
  no market series, and are labelled as such in the result.
- **Abnormal return:** `AR_t = R_t - (alpha + beta * R_mt)`.
  **CAR** is the sum of AR over the event window; **CAAR** is the
  mean CAR across events.
- **Significance:** t-statistic `CAR / (sd(AR_est) * sqrt(11))`
  per event and `CAAR / (sd(CARs) / sqrt(n_events))` across events;
  plus a seeded bootstrap p-value (2000 resamples of the
  estimation-window abnormal returns, seed 20261114) for the CAAR.
  An event-study result is called significant only if BOTH
  |t| > 1.96 AND bootstrap p < 0.05. **Small-n caveat, stated in
  every result:** n = 8 events, so the t-test's normality
  assumption is thin and the bootstrap is the more honest of the
  two — neither is a proof.
- **NEPSE events:** dividend, bonus, right and book-closure, from a
  user-supplied CSV with columns
  `symbol,event_date,event_type,detail` (detail optional), validated
  by `load_event_csv` — unknown event types and bad dates raise
  loudly, never silently skipped. NEPSE data is CSV-only by design;
  no live feed is claimed or used.
- **Global events:** earnings events, caller-supplied dates plus
  price series, same method. The demo includes 2 synthetic earnings
  events.

## Floorsheet importer (fixed here — no evaluation, just the contract)

- Input: a user-supplied CSV with columns
  `date,broker,symbol,side,quantity,price` (`#` comment lines
  allowed and skipped; the bundled demo file carries a SYNTHETIC
  header comment). `side` must be `buy` or `sell`; `quantity` a
  positive integer; `price` positive. Any bad row raises
  `FloorsheetError` naming the line — never silently skipped.
- Analytics: per broker — total buy/sell quantity and value, net
  flow (buy value minus sell value), net quantity; per symbol —
  top buyers and top sellers by value; concentration — top-3 broker
  share of a symbol's traded value and the Herfindahl-Hirschman
  index of broker shares. NEPSE floorsheet data is user-supplied
  CSV only; no live feed exists or is claimed.

## Decision rule (the verdict, fixed before running)

Per ranking rule, pooled across the 12 rebalances: the rule
**beats zero** only if BOTH hold:

1. its mean net top-minus-bottom spread is greater than zero, and
2. the 95% bootstrap CI on the mean spread (2000 resamples, seed
   20261114) lies **entirely above zero**.

Otherwise the rule is labelled **"no edge"** — in the model card
and in the code's verdict strings. A win before costs never counts.
A win on one rebalance alone never counts. The event-study verdict
is "significant" only under the both-tests rule above, else "no
significant abnormal return".

## What counts as "models tried"

Four ranking rules (momentum, value, quality, composite) plus one
event-study method (market model). No parameter search was run and
none will be run for this PR: the 126/21 momentum window, the
proxy definitions, the 12 rebalances, the 21-day forward window,
the cost fractions and the event-study windows are all fixed above.
If no rule beats zero, the PR still ships with the "no edge"
labels — the evaluation is the deliverable either way.

## Reproducibility

The evaluation is run by `scripts/evaluate_cross_sectional.py`
(stdlib only; no network). Its output is the input to
`docs/cross-sectional-model-card.md`. The offline test suite
(`tests/test_cross_sectional.py`) never touches the network: it runs
the same ranking, cost, spread, event-study and floorsheet code on
hand-built fixture series, including positive controls (a planted
spread and a planted event jump) that prove the decision rule can
say "beats zero" / "significant" when the data warrants it.
