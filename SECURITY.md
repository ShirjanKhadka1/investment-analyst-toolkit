# Security Policy

## Reporting a vulnerability

If you find a security issue in this repository, please do **not** open a
public issue and do **not** publish exploit details publicly first.

Instead, please report it privately:

- Use GitHub's private vulnerability reporting for this repository
  (Security tab → Report a vulnerability), if available; or
- Contact the maintainer via the profile at <https://github.com/ShirjanKhadka1>.

Include what you found, the affected file and version or commit, and steps
to reproduce — without any credentials, private data, or access to anyone
else's account or system.

## What this covers

This repository is research and education material. It contains no
credentials, no private data, and no live trading or payment code. If a
report involves credentials or private data, it will be treated as urgent
and the exposed material will be removed first.

## House rules

- Research and education only. Never investment advice, and never a
  buy/sell/hold recommendation.
- No credentials anywhere, in code, examples, or issue reports.
